## 🎮 The Ultimate School Escape

School Wi-Fi is a fortress. Every gaming website is blocked. Every proxy is detected. Every unblocked game gets patched within a week. For students who just want to play a quick game during a free period, it feels impossible.

**Classroom10x Gaming Platform** is the ultimate solution. This is not just another unblocked games website. It is a comprehensive, open-source gaming platform designed specifically to bypass school Chromebook restrictions.

This repository provides a massive library of HTML5 games, an advanced proxy system that hides the game inside a legitimate-looking educational domain, and a "panic button" that instantly switches your screen to a fake Google Classroom page. It is the most sophisticated school gaming tool on the internet.

## 🧠 Under The Hood: The Cloaking Engine

How does the platform bypass school filters? It uses a technique called **Domain Fronting**.

When you load a game, the platform does not connect directly to the gaming server. Instead, it connects to a legitimate educational domain (like `google.com` or `classroom.google.com`). The request is encrypted, so the school's firewall cannot see what is inside.

Our Service Worker intercepts the request and routes it to the actual gaming server. The firewall only sees a connection to Google, so it never blocks it.
